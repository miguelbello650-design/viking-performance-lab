# Regla 001 — Comparación contextual de actividades

## Estado

Versión comparison-context-v1, activa como regla exploratoria del MVP.

## Objetivo

Describir cambios entre la actividad más reciente y la anterior del mismo atleta sin afirmar mejora, pérdida de rendimiento ni causalidad.

## Datos observados requeridos

- duración;
- distancia;
- ascenso;
- frecuencia cardiaca media;
- dos o más actividades normalizadas del atleta.

## Cálculos

Se calcula la diferencia de cada campo disponible entre la actividad más reciente y la anterior.

## Interpretación permitida

Solo se puede indicar que existe base mínima para una comparación contextual. La regla no usa umbrales universales y no transforma el cambio en una evaluación de rendimiento.

## Hipótesis permitida

Si hay cambios entre las actividades, se puede formular que podrían corresponder a objetivos o contextos distintos de sesión. Es una hipótesis, no un hecho.

## Recomendación

No genera recomendaciones automáticas. Toda revisión queda a cargo del entrenador.

## Insuficiencia de datos

Si falta cualquiera de los campos requeridos, la respuesta debe ser no concluyente y mostrar qué dato falta.
