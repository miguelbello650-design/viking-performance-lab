# Regla 002 — Eficiencia aeróbica observada

## Estado

Versión aerobic-efficiency-v1, activa como regla condicionada del MVP.

## Objetivo

Comprobar si existe evidencia mínima para revisar conjuntamente velocidad media y frecuencia cardiaca media entre actividades del mismo atleta.

## Datos observados requeridos

- dos o más actividades normalizadas;
- velocidad media en las actividades comparadas;
- frecuencia cardiaca media en las actividades comparadas;
- contexto de disciplina y tipo de elemento.

## Cálculos

Se calculan las diferencias de velocidad media y frecuencia cardiaca media entre la actividad más reciente y la anterior.

## Interpretación permitida

La regla solo confirma si existe base de datos suficiente para una revisión conjunta. No afirma eficiencia, mejora ni pérdida de rendimiento.

## Hipótesis permitida

Si existe una variación conjunta, puede formularse una hipótesis para revisión del entrenador. La hipótesis no establece causalidad.

## Recomendación

No genera recomendaciones automáticas.

## Insuficiencia de datos

Si falta velocidad media o frecuencia cardiaca media, la respuesta es no concluyente y debe indicar el campo faltante.
