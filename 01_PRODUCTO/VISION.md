# Visión

Viking Performance Lab será una plataforma de inteligencia deportiva para entrenadores y atletas de deportes de resistencia.

## Disciplinas iniciales
- Trail running
- Running de asfalto
- Ciclismo

## Principios
- El entrenador mantiene la decisión final.
- Los cálculos deben ser explicables.
- Los análisis deben ser reproducibles.
- Las recomendaciones deben mostrar incertidumbre.
- El producto debe soportar varias fuentes.
- El núcleo no debe depender de una sola disciplina.
- La privacidad del atleta es prioritaria.
