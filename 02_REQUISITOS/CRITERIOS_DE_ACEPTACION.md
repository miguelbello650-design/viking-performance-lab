# Criterios de aceptación

## Importación
- Identifica formato
- Reporta errores
- Advierte duplicados
- Conserva trazabilidad

## Análisis
- Clasifica cada conclusión
- Permite rastrear cálculos
- No oculta datos faltantes
- Usa reglas de la disciplina correcta

## Estrategia
- Se presenta como propuesta
- Puede modificarse
- No se publica automáticamente
- Explica los datos usados
