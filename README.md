# Viking Performance Lab

Plataforma de inteligencia deportiva para entrenadores y atletas de deportes de resistencia.

## Disciplinas iniciales
- Trail running
- Running de asfalto
- Ciclismo

## Propósito
Viking Performance Lab no reemplaza al entrenador ni pretende competir con TrainingPeaks. Su objetivo es actuar como una capa de inteligencia que transforma datos deportivos en análisis, comparaciones, alertas, estrategias y apoyo a la toma de decisiones.

## Principio del producto
> Los datos describen lo que ocurrió. Viking Performance Lab ayuda a interpretar por qué ocurrió y qué conviene revisar después.

## Estado
Fase inicial de definición y diseño. No se debe comenzar el desarrollo funcional hasta aprobar producto, requisitos, analítica y arquitectura.
